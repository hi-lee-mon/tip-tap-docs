# Tiptap ドキュメント 日本語訳（Editor・Guides）

[Tiptap](https://tiptap.dev/) 公式ドキュメントのうち、オープンソース版エディタ（Editor）とガイド（Guides）を日本語に訳したものです。フレームワーク別のページは React と Next.js だけを残しています。対象は Tiptap 3 系（`@tiptap/react` ^3.32.0 で確認）です。

- 原文: [ueberdosis/tiptap-docs](https://github.com/ueberdosis/tiptap-docs) の `src/content/`、コミット `5b0902e`（2026-10-14）
- ライセンス: 原文は MIT ライセンスです。著作権表示は [LICENSE](LICENSE) にあります
- 訳語のそろえ方: [GLOSSARY.md](GLOSSARY.md)
- 範囲と形式を決めた理由: [ADR](../adr/20261018-1240-tiptap-docs-ja-translation.md)

## サイトとして読む

リポジトリのルートで次を実行し、表示された URL（`http://localhost:5173` など）をブラウザで開きます。

```bash
pnpm install
pnpm docs:dev
```

`pnpm docs:build` で静的なサイトを `docs/ja/.vitepress/dist/` に書き出せます。

## 読むときの注意

- 各ページの冒頭に、原文ページへのリンクがあります。訳が怪しいと感じたら原文を確認してください
- デモは埋め込めないため「デモを開く」のリンクにしています
- 見出しを訳したので、ページ内アンカー（`#usage` など）へのリンクは飛び先がずれることがあります
- 名前に `key` や `token` を含む4ページは、作業環境の権限設定（秘密情報を守るための読み取り禁止ルール）に当たって訳せていません。原文はリンク先の公式サイトで読めます
