# newlineInCode コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/nodes-and-marks/newline-in-code](https://tiptap.dev/docs/editor/api/commands/nodes-and-marks/newline-in-code)

`newlineInCode` は、現在のコードブロックに改行を挿入します。選択範囲がある場合は、その選択範囲を改行文字で置き換えます。

## newlineInCode コマンドの使い方

```js
editor.commands.newlineInCode()
```
