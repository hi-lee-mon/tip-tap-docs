# exitCode コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/nodes-and-marks/exit-code](https://tiptap.dev/docs/editor/api/commands/nodes-and-marks/exit-code)

`exitCode` コマンドは、選択範囲が `code` 要素の中にあるとき、選択範囲の後ろにデフォルトのブロックを作り、カーソルをそのブロックに移します。

## exitCode コマンドの使い方

```js
editor.commands.exitCode()
```
