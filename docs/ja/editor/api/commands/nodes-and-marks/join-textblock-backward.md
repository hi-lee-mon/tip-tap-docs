# joinTextblockBackward コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/nodes-and-marks/join-textblock-backward](https://tiptap.dev/docs/editor/api/commands/nodes-and-marks/join-textblock-backward)

joinBackward の機能を絞った版です。カーソルがテキストブロックの先頭にあるときに、現在のテキストブロックを直前のテキストブロックと結合しようとすることだけを行います。[関連](https://prosemirror.net/docs/ref/#commands.joinTextblockBackward)

## joinTextblockBackward コマンドの使い方

```js
editor.commands.joinTextblockBackward()
```
