# joinTextblockForward コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/nodes-and-marks/join-textblock-forward](https://tiptap.dev/docs/editor/api/commands/nodes-and-marks/join-textblock-forward)

joinForward の機能を絞った版です。カーソルがテキストブロックの末尾にあるときに、現在のテキストブロックを直後のテキストブロックと結合しようとすることだけを行います。[関連](https://prosemirror.net/docs/ref/#commands.joinTextblockForward)

## joinTextblockForward コマンドの使い方

```js
editor.commands.joinTextblockForward()
```
