# selectTextblockEnd コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/select-textblock-end](https://tiptap.dev/docs/editor/api/commands/select-textblock-end)

`selectTextblockEnd` は、現在のブロックが有効なテキストブロックであれば、カーソルをそのテキストブロックの末尾に移します。

## selectTextblockEnd コマンドの使い方

```js
editor.commands.selectTextblockEnd()
```
