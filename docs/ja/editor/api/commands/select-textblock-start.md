# selectTextblockStart コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/select-textblock-start](https://tiptap.dev/docs/editor/api/commands/select-textblock-start)

`selectTextblockStart` は、現在のブロックが有効なテキストブロックであれば、カーソルをそのテキストブロックの先頭に移します。

## selectTextblockStart コマンドの使い方

```js
editor.commands.selectTextblockStart()
```
