# deleteSelection コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/selection/delete-selection](https://tiptap.dev/docs/editor/api/commands/selection/delete-selection)

`deleteSelection` コマンドは、選択中のノードを削除します。選択範囲がなければ、何も削除しません。

## deleteSelection コマンドの使い方

```js
editor.commands.deleteSelection()
```
