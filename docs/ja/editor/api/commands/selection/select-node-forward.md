# selectNodeForward コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/selection/select-node-forward](https://tiptap.dev/docs/editor/api/commands/selection/select-node-forward)

選択範囲が空で、かつテキストブロックの末尾にあるとき、`selectNodeForward` は可能であれば現在のテキストブロックの後ろにあるノードを選択します。

## selectNodeForward コマンドの使い方

```js
editor.commands.selectNodeForward()
```
