# selectParentNode コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/selection/select-parent-node](https://tiptap.dev/docs/editor/api/commands/selection/select-parent-node)

`selectParentNode` は、選択中のノードの親ノードを探し、選択範囲をそのノードへ移そうとします。

## selectParentNode コマンドの使い方

```js
editor.commands.selectParentNode()
```
