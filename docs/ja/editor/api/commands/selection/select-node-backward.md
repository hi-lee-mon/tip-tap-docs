# selectNodeBackward コマンド

> 原文: [https://tiptap.dev/docs/editor/api/commands/selection/select-node-backward](https://tiptap.dev/docs/editor/api/commands/selection/select-node-backward)

選択範囲が空で、かつテキストブロックの先頭にあるとき、`selectNodeBackward` は可能であれば現在のテキストブロックの前にあるノードを選択します。

## selectNodeBackward コマンドの使い方

```js
editor.commands.selectNodeBackward()
```
