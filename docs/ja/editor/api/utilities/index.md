# Tiptap のユーティリティ

> 原文: [https://tiptap.dev/docs/editor/api/utilities](https://tiptap.dev/docs/editor/api/utilities)

Tiptap のユーティリティは Editor API を補うものです。エディタやコンテンツを扱う処理を改善・拡張するためのツールをそろえています。

## ユーティリティ一覧

| ユーティリティ名                                               | 説明                                                                            |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [`HTML Utility`](html.md)               | JSON と HTML の相互変換をサーバー側で行います。                                     |
| [`JSX`](jsx.md)                         | 拡張機能を HTML にレンダリングする方法を JSX で記述します。                             |
| [`Position Utilities`](position.md)     | ドキュメントの変更に合わせて、エディタ内の位置を追跡・更新します。                     |
| [`Static Renderer`](static-renderer.md) | エディタのインスタンスなしで、JSON コンテンツを HTML、Markdown、React コンポーネントとしてレンダリングします。 |
| [`Suggestion Utility`](suggestion.md)   | カスタマイズできる入力補完の候補をエディタに追加します。                                |
| [`Tiptap for PHP`](https://tiptap.dev/docs/editor/api/utilities/tiptap-for-php)   | Tiptap の機能を PHP のプロジェクトに組み込みます。                                   |
