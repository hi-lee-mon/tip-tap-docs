# ドキュメントを理解して編集する AI エージェントを作る

> 原文: [https://tiptap.dev/docs/editor/extensions/functionality/ai-toolkit](https://tiptap.dev/docs/editor/extensions/functionality/ai-toolkit)

ドキュメントを自在に編集できる AI エージェントを作ったり、Tiptap のドキュメントに独自の AI 機能を加えたりできます。AI Toolkit には柔軟な基本部品と既製のツールがそろっており、AI が Tiptap のドキュメントを読み取り、編集し、操作できるようになります。エディタがあってもなくても使えます。

インストール、設定、詳しいガイドは **[AI Toolkit のドキュメント](https://tiptap.dev/docs/ai/ai-toolkit/)** を参照してください。
