# エディタにスナップショットを組み込む

> 原文: [https://tiptap.dev/docs/editor/extensions/functionality/snapshot](https://tiptap.dev/docs/editor/extensions/functionality/snapshot)

Snapshot 拡張機能を使うと、ドキュメントの版（リビジョン）を組み込んで管理できます。すべての変更を記録するので、ユーザーは以前のバージョンを表示したり、必要に応じて変更を元に戻したりできます。

> [!TIP]
> **詳細**
>
> Snapshot 拡張機能の組み込み方、インストール、設定の詳細は、[機能のページ](https://tiptap.dev/docs/collaboration/documents/snapshot)を参照してください。
