# ページ単位のレイアウト

> 原文: [https://tiptap.dev/docs/editor/extensions/functionality/pages](https://tiptap.dev/docs/editor/extensions/functionality/pages)

従来の1枚続きのエディタを、ページ単位で編集する本格的なインターフェースに変えられます。Tiptap Pages は余白、改ページ、レイアウトの調整機能を備えており、ページ構成を保ったきちんとしたドキュメントを作れます。

> [!TIP]
> **詳細**
>
> インストール、設定、組み込み方の詳細は、[Pages の機能のページ](https://tiptap.dev/docs/pages/getting-started/overview)を参照してください。
