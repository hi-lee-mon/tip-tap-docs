# Snapshot Compare 拡張機能

> 原文: [https://tiptap.dev/docs/editor/extensions/functionality/snapshot-compare](https://tiptap.dev/docs/editor/extensions/functionality/snapshot-compare)

Snapshot Compare 拡張機能を使うと、ドキュメントの2つのバージョンの違いを目で見て確認できます。チームで共同編集している場合も1人で編集している場合も、スナップショット間の差分を強調表示し、何がどう変わり、誰が変更したのかを示します。

> [!TIP]
> **詳細**
>
> Snapshot Compare 拡張機能の組み込み方、インストール、設定の詳細は、[機能のページ](https://tiptap.dev/docs/collaboration/documents/snapshot-compare)を参照してください。
