# エディタに基本的な AI ワークフローを組み込む

> 原文: [https://tiptap.dev/docs/editor/extensions/functionality/ai-generation](https://tiptap.dev/docs/editor/extensions/functionality/ai-generation)

Basic AI Generation 拡張機能を使うと、AI を使ったコマンドやテキスト・画像の生成をエディタに組み込めます。ドキュメントの内容を理解するエージェントを作りたい場合や、より柔軟に扱いたい場合は **[AI Toolkit](https://tiptap.dev/docs/ai/ai-toolkit/)** を参照してください。

Basic AI Generation 拡張機能の組み込み方、インストール、設定の詳細は、**[Basic AI Generation のドキュメント](https://tiptap.dev/docs/ai/basic/overview)** を参照してください。
