# インポート

> 原文: [https://tiptap.dev/docs/editor/extensions/functionality/import](https://tiptap.dev/docs/editor/extensions/functionality/import)

docx、odt、Markdown などのさまざまな形式のドキュメントをインポートし、Tiptap の JSON 形式に変換します。
