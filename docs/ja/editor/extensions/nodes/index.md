# ノードの拡張機能

> 原文: [https://tiptap.dev/docs/editor/extensions/nodes](https://tiptap.dev/docs/editor/extensions/nodes)

ドキュメントを木構造と考えると、ノードはその木に含まれるコンテンツの種類の 1 つです。段落、見出し、コードブロックなどがノードの例です。ただし、ノードはブロックとは限りません。@メンションのように、テキストと同じ行にインラインでレンダリングされるノードもあります。
