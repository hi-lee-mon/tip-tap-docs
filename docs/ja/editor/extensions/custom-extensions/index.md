# カスタム拡張機能の作り方

> 原文: [https://tiptap.dev/docs/editor/extensions/custom-extensions](https://tiptap.dev/docs/editor/extensions/custom-extensions)

Tiptap の強みのひとつは拡張性です。用意された拡張機能に縛られる必要はなく、エディタは好みに合わせて拡張する前提で作られています。

カスタム拡張機能を使うと、新しい種類のコンテンツや新しい機能を追加できます。既存のものに上乗せすることも、ゼロから作ることもできます。まずは、既存のノード・マーク・拡張機能を拡張するよくある例から始めます。

ゼロから作る方法は [新しく作る](create-new/index.md) のページで説明します。ただ、既存の拡張機能を拡張する場合も新しく作る場合も、必要な知識は同じです。
