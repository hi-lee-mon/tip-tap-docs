# ノードとマーク

> 原文: [https://tiptap.dev/docs/editor/core-concepts/nodes-and-marks](https://tiptap.dev/docs/editor/core-concepts/nodes-and-marks)

ドキュメントを木構造と考えると、ノードはその木に含まれるコンテンツの種類です。段落、見出し、コードブロックなどがノードにあたります。ただし、ノードはブロックとは限りません。@メンションのように、テキストと同じ行にインラインでレンダリングされるノードもあります。スタイルや操作をそれぞれ変えられる、独立したコンテンツの断片と考えてください。

マークは、ノードの特定の部分に適用できます。**太字**、_斜体_、~~取り消し線~~のテキストがその例です。[リンク](#)もマークです。テキストにスタイルや注釈を付ける手段と考えてください。

## 違い

ノードとマークは似たところもありますが、用途が違います。ノードはドキュメントを組み立てる部品で、コンテンツの構造と階層を決めます。一方マークは、テキストにスタイルや注釈を付けるために使います。ノードのどの部分にも適用できますが、ドキュメントの構造は変えません。
